Aegis Forensic Assistant is a security platform designed to automate the SOC incident-analysis workflow by integrating machine learning, rule-based correlation, MITRE ATT&CK mapping, and LLM-generated investigation guidance.

Key technical areas:

- Automated the SOC incident-analysis workflow through machine learning, correlation logic, MITRE ATT&CK mapping, and LLM-generated investigation guidance
- Achieved **91.5% weighted precision** across **10 threat categories** and more than **25 attack types**
- Trained and calibrated a **Random Forest classifier** using CICIDS2017/2019 network-security datasets
- Implemented automated security-log analysis for files up to **2 GB**
- Supported **4 file formats** and **5 log-source types**
- Built a scalable normalization and chunked-ingestion pipeline
- Created a RAG pipeline using **1,536-dimensional embeddings**, **pgvector**, and **HNSW search**
- Returned the top **5 matching MITRE ATT&CK techniques** with confidence scores
- Implemented PostgreSQL **Row-Level Security across 17 tables**
- Added JWT-based authentication and role-based access for **Admin, Analyst, and Viewer** users
